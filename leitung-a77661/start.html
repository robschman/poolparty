Der Start

Namen eintippen, Größe wählen, Knopf drücken. Jedes Team bekommt seinen eigenen QR-Code — damit ist es sofort im richtigen Team und in der richtigen Fassung.

Schritt 1Wer ist da?

Ein Name je Zeile. Die Reihenfolge ist egal — es wird gemischt.

Schritt 2Wie groß soll die Jagd sein?

Entscheide das am Partymorgen — nach Wetter und Laune.

Schritt 3Adresse der App

Nur ändern, wenn die App woanders liegt.

Schritt 4Die Teams

Noch nicht ausgelost.

So geht es weiter: Halte jedem Team seinen eigenen Code hin — mit der normalen iPhone-Kamera draufhalten, auf die Einblendung tippen, fertig. Sie landen direkt in ihrem Team. Nicht die Codes vertauschen, sonst bekommen beide dieselben Rätsel-Hälften.
Ein Handy je Team. Der Spielstand wird auf dem Handy gespeichert, das den Code gescannt hat. Wenn ein zweites Handy denselben Code scannt, fängt es bei null an — das ist kein Fehler, die zwei wissen nichts voneinander.

Die Namen bleiben in diesem Browser. Sie werden nirgendwohin geschickt und stehen auch nicht im QR-Code — dort steht nur die Fassung und die Teamnummer.
