Was fertig ist

Die App läuft — es fehlen nur noch deine Orte

Die Schnitzeljagd ist eine Browser-App: Die Kids scannen einen QR-Code, die Seite geht auf, sie wählen ihr Team — fertig. Nichts installieren, kein App-Store, kein Konto. Läuft auf iPhone und Android gleich.

Ich habe sie im mobilen Browser komplett durchgespielt: Start, Teamwahl, alle Stationsarten, falsche Antworten, Tipps, die Handy-aus-Aktion, das Finale mit Konfetti. Keine Fehler.

Was drin ist

  • 8 Stationen plus Begrüßung und Finale — je nach Tempo 80 bis 95 Minuten
  • Fünf Aufgabenarten: Antwort eintippen · Quiz zum Antippen · Foto-Aufträge zum Abhaken · eine Aufgabe, die nur zusammen mit einem anderen Team geht · und der Gag
  • Der Gag ist eingebaut — die Handy-abschalten-Aktion, siehe unten
  • Punkte und Uhr laufen oben mit, Fortschritt wird gespeichert: Handy aus, Akku leer, Seite geschlossen — es geht dort weiter, wo sie waren
  • Buchstaben-Sammlung: Jede Station gibt einen Buchstaben, alle acht ergeben das Losungswort für den Türsteher (aktuell VIPPARTY)
  • Notfallknopf für dich: Krone oben links 3× antippen, Code 9999 — damit kannst du eine Station überspringen, wenn ein Team feststeckt
  • Schwarz-Gold, umschaltbar auf Schwarz-Silber mit einem Wort in einer Datei

Der Gag — Station 4

Mitten in der Jagd wird der Bildschirm rot: „Sicherheitsstufe Rot. Ein fremdes Gerät versucht, sich in eure VIP-Verbindung einzuklinken. Schaltet sofort alle Handys komplett aus.“ Dazu ein Countdown von 60 Sekunden.

Schalten sie die Handys wirklich aus und öffnen die Seite danach wieder, steht dort: „Danke, dass ihr eure Handys neu gestartet habt. Die Verbindung ist wieder sicher. Wir machen weiter.“ — und klein darunter: „Unter uns: Es hätte auch ohne funktioniert. Aber ihr wart wirklich überzeugend.“

Machen sie es nicht, läuft der Countdown ab und es geht genauso weiter. Es kann also nichts schiefgehen — egal wie sie sich entscheiden.

Wie das Emoji-Duell funktioniert

Jedes Team sieht auf seinem Handy ein eigenes Geheimwort — Kaviar beim einen Team, Limousine beim anderen. Bei dieser Station muss ein Team das Geheimwort eines anderen Teams eintragen. Und das bekommt es nur, wenn es dessen Emoji-Rätsel gelöst hat. Das eigene Wort erkennt die App und lehnt es ab — schummeln geht also nicht.

Wo die App hinkommt

poolparty.robschman.at

Deine Aufteilung ist richtig: Sport über schrittfuerschrittfit.at, alles andere über robschman.at. Eine private Geburtstagsfeier gehört nicht auf die Domain deiner Fitnessmarke.

Korrektur zu dem, was ich vorher gesagt habe

Ich hatte behauptet, eine Subdomain bei schrittfuerschrittfit.at „kostet nichts extra“. Laut deinem Memo zu robschman programming ist das SSL-Kontingent des IONOS-Pakets mit 3 von 3 aufgebraucht — deshalb ist robschman.at im August überhaupt erst auf GitHub Pages umgezogen. Der Weg unten umgeht diese Frage.

Mein Vorschlag: GitHub Pages

Genau so, wie robschman.at selbst schon läuft. Zertifikat gratis von GitHub, erneuert sich allein, kein SSL-Kontingent.

  1. Neues öffentliches Repository poolparty auf github.com anlegen
  2. Den Inhalt von _ZUM-HOCHLADEN hineinziehen
  3. Bei IONOS im DNS von robschman.at einen CNAME anlegen: poolparty → robschman.github.io
  4. Im Repo unter Settings → Pages die Custom domain poolparty.robschman.at eintragen
  5. Auf den grünen Haken warten, dann Enforce HTTPS ankreuzen

Die ausführliche Fassung

Jeder Klick einzeln, dazu Weg B über den IONOS-Webspace, die vier DNS-Einträge bei robschman.at, die du nicht anfassen darfst, Prüfbefehle fürs Terminal und die Fehlersuche: Werkzeuge/Subdomain-Anleitung.html

Zwei Dinge zum Merken: Die .htaccess brauchst du bei GitHub Pages nicht — die versteht nur ein Apache-Server, https macht GitHub selbst. Die leere Datei .nojekyll dagegen muss mit, sonst liefert GitHub die Seite nicht unverändert aus.

Es bleibt privat: kein Impressum, keine UID, keine GISA-Nummer — es ist eine Geburtstagsfeier, kein Angebot. Die Seite ist auf noindex gestellt und hat eine robots.txt dabei.

Frage 2: Wie kommt es auf den Server

Bei GitHub Pages: hineinziehen statt hochladen

Wenn du den GitHub-Weg nimmst, brauchst du FileZilla gar nicht — du ziehst die Dateien im Browser ins Repository. Die Anleitung dazu steht in Werkzeuge/Subdomain-Anleitung.html. Der FileZilla-Weg unten gilt für Weg B über den IONOS-Webspace.

Alles, was hochmuss, liegt im Ordner _ZUM-HOCHLADEN — genau dasselbe Muster wie bei Schritt für Schritt fit.

VIP-Schnitzeljagd/ ├── _ZUM-HOCHLADEN/ ← dieser Inhalt kommt auf den Server │ ├── index.html │ ├── css/vip.css │ ├── js/stationen.js ← hier trägst du alles ein │ ├── js/app.js │ ├── fonts/ │ ├── fotos/ ← deine Bilder │ ├── robots.txt │ ├── .nojekyll ← leer, aber nötig für GitHub Pages │ └── htaccess-hochladen-als-punkt-htaccess.txt nur für IONOS, nicht für GitHub ├── Werkzeuge/ ← bleibt am Mac, nicht hochladen │ ├── Erkundungs-Blatt.html ← damit gehst du die Runde │ ├── Video-Anleitung.html ← Drehbuch fürs Video │ ├── Subdomain-Anleitung.html ← IONOS Schritt für Schritt │ ├── QR-Plakat.html │ └── Spielleiter-Zettel.html ├── Uebersicht.html ← diese Seite └── 00_Memo.md
  1. FileZilla öffnen, wie gewohnt auf den IONOS-Webspace verbinden
  2. Rechts in den neuen Ordner /poolparty wechseln
  3. Links den Inhalt von _ZUM-HOCHLADEN markieren — nicht den Ordner selbst, sondern was drin ist — und rüberziehen
  4. Auf dem Server htaccess-hochladen-als-punkt-htaccess.txt umbenennen in .htaccess (mit Punkt vorne, ohne .txt)
    Erst machen, wenn https steht — siehe oben.
  5. Am Handy https://poolparty.robschman.at aufrufen

Vorher am Mac ausprobieren, ohne Server — Terminal öffnen:

cd "/Users/robschmansimac/Claude Projekte/VIP-Schnitzeljagd/_ZUM-HOCHLADEN"

Kleinen Testserver starten:

python3 -m http.server 8899

Dann im Browser http://localhost:8899 aufrufen. Mit Strg + C beendest du den Testserver wieder.

Frage 3: Wie änderst du Inhalte

Eine einzige Datei: stationen.js

Alles Inhaltliche steht in _ZUM-HOCHLADEN/js/stationen.js. Du öffnest sie mit TextEdit oder BBEdit und änderst nur den Text zwischen den Anführungszeichen. Programmieren musst du nichts.

Vorher eine Sicherungskopie machen — dann kann nichts passieren:

cd "/Users/robschmansimac/Claude Projekte/VIP-Schnitzeljagd/_ZUM-HOCHLADEN/js"
cp stationen.js stationen.js.backup

Die drei Regeln

  1. Text steht immer zwischen "Anführungszeichen"
  2. Am Zeilenende steht ein Komma
  3. Klammern { } und Anführungszeichen nicht löschen

Was du überall suchen musst

Ich habe jede offene Stelle mit HIER … EINTRAGEN markiert. Wenn du das Wort HIER in der Datei suchst, findest du alle. Es sind noch acht Stellen — alle davon füllt das Erkundungs-Blatt und das Video. Das Datum und die Teams habe ich schon eingetragen.

Fotos einbauen

  1. Foto am iPhone machen, per AirDrop auf den Mac
  2. In den Ordner _ZUM-HOCHLADEN/fotos legen, kurzer Name ohne Leerzeichen und Umlaute, z. B. tuersteher.jpg
  3. In stationen.js bei der Station eintragen: foto: "fotos/tuersteher.jpg",

Vorher die Bilder verkleinern — am Mac in der Vorschau unter Werkzeuge → Größenkorrektur auf etwa 1200 Pixel Breite. Sonst wartet jedes Kind im Ortsnetz ewig, bis das Bild da ist.

Silber statt Gold

In stationen.js oben: farbe: "gold" → farbe: "silber". Mehr nicht, das ganze Design zieht mit.

Nach jeder Änderung wichtig

Ganz oben in stationen.js steht version: "1". Zähl die Zahl bei jeder Änderung um eins hoch. Sonst zeigen Handys, die schon einmal da waren, noch die alte Fassung. Denselben Trick kennst du vom ?v= auf der Fitness-Website.

Frage 4: Der QR-Code

Fertiges Plakat zum Ausdrucken

Im Ordner Werkzeuge liegt QR-Plakat.html. Doppelklick, es geht im Browser auf: A4-Plakat in Schwarz-Gold mit dem QR-Code, „Scanne mich“ und der Adresse darunter. Die Adresse oben im Feld ändern → der Code baut sich sofort neu. Ich habe ihn mit einem echten Scanner-Programm geprüft, er wird sauber gelesen.

  • Drucken mit ⌘ + P — im Druckdialog unbedingt Hintergrundgrafiken anhaken, sonst kommt das Plakat weiß heraus
  • Über den Knopf Als Bild speichern bekommst du den Code auch als PNG — praktisch für die WhatsApp-Gruppe der Eltern
  • Die Adresse steht dort schon auf poolparty.robschman.at
  • Mach drei Ausdrucke — einen pro Team und einen als Reserve. Und schreib die Adresse zusätzlich lesbar dazu — wenn eine Kamera streikt, tippt man sie ab

Zusatztipp fürs iPhone

Nach dem Scannen: Teilen-Knopf → Zum Home-Bildschirm. Dann liegt die Jagd als eigenes Symbol (goldene Krone) am Handy und startet ohne Browser-Leiste, wie eine richtige App. Das habe ich eingebaut.

Station 2

Dein Video — zwei Wege ins Spiel

Du machst das Video selbst. Die ausführliche Anleitung mit Drehbuch, Aufstellung und Wort-für-Wort-Text liegt in Werkzeuge/Video-Anleitung.html. Hier nur das Wichtigste:

  • Quer filmen, nicht hochkant — der Player in der App ist quer
  • 1080p, 30 Bilder einstellen (Einstellungen → Kamera → Video aufnehmen). In 4K wird die Datei zu groß fürs Handynetz
  • Das Codewort sagen und gleichzeitig auf einem Blatt hochhalten — dann kommen auch die Teams weiter, bei denen es zu laut ist
  • Codewort ist derzeit GOLDFISCH

Neu: Du brauchst kein YouTube

Ich habe die App so erweitert, dass sie auch eine Videodatei direkt von deinem Server abspielt. Datei nach fotos/botschaft.mp4 legen, in stationen.js eintragen — fertig. Kein Konto, keine Werbung, keine Einstellungen, die man falsch machen kann.

YouTube geht weiterhin (dann auf Nicht gelistet stellen) — sinnvoll, wenn die Datei größer als 30 MB wird.

Der Partytag

Checkliste und Material

Am Abend vorher

  • Adresse am eigenen Handy aufrufen — geht sie über https auf?
  • Eine Station wirklich durchspielen, nicht nur anschauen
  • QR-Plakate ausdrucken (drei Stück)
  • Spielleiter-Zettel ausdrucken — liegt in Werkzeuge, listet alle Lösungen, die Geheimwörter und den Notfallcode. Nicht herzeigen.
  • Die Wege selbst einmal abgehen: Ist die Hausnummer noch dran? Steht das Schild noch?

Material

  • Drei ausgedruckte QR-Plakate, dazu die Adresse lesbar auf einen Zettel
  • Eine Powerbank pro Team — Kamera, Bildschirm und Suchen fressen Akku, und mitten in der Jagd ohne Handy ist bitter
  • Etwas zum Schreiben pro Team für die Buchstaben (die App zeigt sie zwar mit, aber Kinder schreiben sie gern auf die Hand)
  • Der „Schatz“ fürs Finale — was auch immer sie am Pool erwartet
  • Deine Handynummer auf jedem QR-Zettel, falls sich ein Team verläuft

Wenn etwas klemmt

  • Team steckt fest → Krone oben links 3× antippen, Code 9999, „Diese Station überspringen“
  • Seite lädt nicht → einmal neu laden. Der Fortschritt ist gespeichert, es geht an derselben Stelle weiter
  • Kein Netz unterwegs → alle Handys vor dem Start einmal die Seite laden lassen, solange sie noch im WLAN sind. Dann ist das Wichtigste im Zwischenspeicher
  • Ein Team hat kein Handy → dazuteilen. Ein Handy pro Team reicht. Bei fünf bis sieben Kindern sind zwei Teams die richtige Größe

Was du vorher regeln solltest

Zwölf- bis Vierzehnjährige allein in der Umgebung: Steck den Bereich vorher ab und sag ihn klar an — welche Straße ist die Grenze, wo wird nicht gequert. Und plane ein, dass mindestens ein Erwachsener mitgeht oder mit dem Rad in der Nähe bleibt. Die App kann das nicht ersetzen.
